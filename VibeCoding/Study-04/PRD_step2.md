# PRD Step 2 — 레시피 생성 시스템

**기간:** 7일  
**목표:** 인식된 재료를 바탕으로 AI가 레시피를 추천하고, 사용자가 재료를 직접 편집할 수 있다

---

## 핵심 기능

- Step 1에서 인식한 재료를 편집 가능한 태그 목록으로 표시
- 재료 추가 / 삭제 기능
- Qwen 모델(`qwen/qwen3.6-plus:free`)로 레시피 3가지 생성
- 레시피 카드 출력 (요리명 / 필요 재료 / 조리 순서)

## 화면 구성

- 재료 태그 편집 영역 (클릭으로 삭제, 입력으로 추가)
- "레시피 추천받기" 버튼
- 레시피 카드 3개 (요리명, 재료, 단계별 조리법)

## API 연동

| 항목 | 내용 |
|------|------|
| 모델 | `qwen/qwen3.6-plus:free` |
| 입력 | 재료 목록 + 레시피 생성 프롬프트 |
| 출력 | 레시피 3개 (JSON 구조화) |
| 백엔드 | Flask — 재료 목록을 받아 OpenRouter에 전달 |

## 일정

| 일차 | 작업 |
|------|------|
| 1일 | 재료 태그 UI 구현 (추가/삭제) |
| 2일 | Qwen 모델 연동, 레시피 프롬프트 작성 |
| 3일 | 응답을 JSON으로 파싱하는 로직 구현 |
| 4일 | 레시피 카드 UI 구현 |
| 5일 | Step 1 → Step 2 전체 흐름 연동 |
| 6일 | 프롬프트 튜닝 (결과 품질 개선) |
| 7일 | 테스트 및 버그 수정 |

## 완료 조건

- 재료를 수정하고 버튼을 누르면 레시피 3개가 카드로 표시된다
