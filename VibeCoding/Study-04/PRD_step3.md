# PRD Step 3 — 사용자 프로필 및 저장 기능

**기간:** 10일  
**목표:** 사용자가 레시피를 저장하고, 프로필 기반으로 맞춤 추천을 받을 수 있다

---

## 핵심 기능

- 레시피 즐겨찾기 저장 (localStorage)
- 저장된 레시피 목록 페이지
- 사용자 프로필 설정 (식단 제한, 알레르기, 선호 음식)
- 프로필 정보를 레시피 추천 프롬프트에 반영

## 화면 구성

- 레시피 카드에 "저장" 버튼 추가
- 즐겨찾기 탭 (저장된 레시피 목록, 삭제 가능)
- 프로필 설정 페이지
  - 알레르기 재료 입력 (예: 견과류, 유제품)
  - 식단 유형 선택 (일반 / 채식 / 비건)
  - 선호 요리 스타일 선택 (한식 / 양식 / 중식 등)
- 모바일 반응형 레이아웃
- 로딩 스피너 및 에러 안내 메시지

## 기술 구현

| 항목 | 내용 |
|------|------|
| 저장 | 브라우저 localStorage |
| 프로필 반영 | 프롬프트에 "○○ 알레르기 있음, 채식주의자" 등 조건 추가 |
| 반응형 | CSS media query, 모바일 이미지 업로드 지원 |

- 프로필을 설정하면 맞춤 레시피가 추천되고, 저장한 레시피를 언제든 다시 볼 수 있다
