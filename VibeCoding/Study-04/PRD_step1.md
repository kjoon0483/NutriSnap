# PRD Step 1 — 이미지 인식 핵심 기능

**기간:** 5일  
**목표:** 냉장고 사진을 업로드하면 AI가 재료를 인식해서 화면에 출력한다

---

## 핵심 기능

- 냉장고 사진 업로드 (파일 선택 또는 드래그 앤 드롭)
- Gemma 모델(`google/gemma-3-27b-it:free`)로 사진 속 재료 목록 추출
- 인식된 재료를 텍스트 목록으로 화면에 표시

## 화면 구성

- 단일 페이지 (HTML + CSS + Vanilla JS)
- 이미지 업로드 영역 (미리보기 포함)
- 재료 인식 결과 출력 영역
- "분석하기" 버튼

## API 연동

| 항목 | 내용 |
|------|------|
| 모델 | `google/gemma-3-27b-it:free` |
| 입력 | 이미지 + 재료 추출 프롬프트 |
| 출력 | 재료 목록 (텍스트) |
| 백엔드 | Python Flask — 이미지를 받아 OpenRouter에 전달 |

## 일정

| 일차 | 작업 |
